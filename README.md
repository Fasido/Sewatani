\# SewaTani



SewaTani adalah aplikasi mobile penyewaan alat pertanian untuk membantu petani di wilayah Indramayu mencari dan memesan alat pertanian secara lebih mudah.



\## Teknologi



\- Flutter

\- Provider

\- Shared Preferences

\- PHP Native API

\- MySQL

\- Firebase Cloud Messaging



\## Fitur Utama



\- Login dan register user

\- Role petani dan vendor

\- CRUD data alat pertanian

\- Booking sewa alat

\- Update status pesanan

\- Notifikasi status pesanan
